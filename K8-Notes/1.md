## Checkpoint 1: Course Overview

**Questions & Answers:**

1. **What problem does Kubernetes solve that Docker alone cannot?**  
   Docker runs containers on a **single machine**. Kubernetes solves production problems: manual server management, scaling failures, downtime during updates, and inconsistent environments (dev/test/prod).

2. **Name two orchestration features.**  
   - Auto-scaling  
   - Self-healing (or load balancing, rolling updates, secret management — any two)

---

## Checkpoint 2: What is K8s?

**Questions & Answers:**

1. **Why is Kubernetes called an "orchestrator"?**  
   It **automates and coordinates** the entire lifecycle of containers across a cluster (deploy, scale, heal, network, update).

2. **How does it differ from just running Docker containers manually?**  
   Docker = single-machine container runtime.  
   Kubernetes = automatic cluster-wide orchestration.

---

## Checkpoint 3: Main K8s Components

**Questions & Answers:**

1. **Difference between a Pod and a Deployment?**  
   Pod = smallest unit (one or few containers, ephemeral).  
   Deployment = higher-level controller that manages multiple identical Pods, scaling, and updates.

2. **When would you choose StatefulSet over Deployment?**  
   Use StatefulSet for **stateful** apps (databases, queues) that need stable identity and ordered scaling. Use Deployment for **stateless** apps.

3. **What problem do Services solve?**  
   Pods get new IPs when they restart. A Service gives a **stable DNS name + IP** and load-balances traffic.

## Checkpoint 4: K8s Architecture

**Questions & Answers:**

1. **What component decides where a pod is scheduled?**  
   The **Scheduler** (part of the Control Plane).

2. **Why is etcd critical?**  
   It is the cluster’s **single source of truth** — a database that stores all cluster state and configuration.

3. **In a local setup, where does the control plane live?**  
   In Minikube, Control Plane + Worker Node run on the **same single machine** (your laptop).

## Checkpoint 5: Minikube and kubectl Setup

**Questions & Answers:**

1. **Run `minikube status` — what do you see?**  
   Shows `host: Running`, `kubelet: Running`, `apiserver: Running`, etc.

2. **Difference between Minikube and a real production cluster?**  
   Minikube = single-node (for learning).  
   Production = multi-master + multi-worker, highly available.
